## 미니특강 1 : 리눅스 명령어 ##
* 리눅스 설치
   . 별도의 컴퓨터에 설치
   . 가상머신 : VMware, Hyper-V, Virtual Box....
   . Docker를 사용 : 완전한 리눅스 X
   . WSL : Windows Subsystem for Linux --> 완전한 리눅스 O
* WSL 간단 개요
  - 시작 : Windows 10 출시 1주년 기념.
* 의미 : 윈도에서도 맥/리눅스의 다기능 터미널을 사용할 수 있다.
   - 명령 프롬프트
   - 파워셸 
  - WSL (완전한 리눅스)을 윈도 OS안에 포함
* WSL 명령어 요약
  wsl  --install   -d  배포판  : 리눅스 설치(배포판 : Ubuntu, Rocky, Centos, .........)
  wsl  --list  --online  : 설치 가능한 리눅스 배포판 목록
	--> 추가로 windows store에서 검색 후 설치 가능

** 리눅스 기본 명령어 **
.pwd : Print Working Directory. 현재 디렉터리 출력	
	C:\ --> 최상위.  리눅스 -->  /
. cd 폴더명 : Change Directory. 폴더 이동
. cd : 자신의 홈폴더로 이동
. ls : List. 폴더 및 파일 목록 출력. 
	-l. d: 디렉터리, -:파일, l:Link(바로가기 아이콘)
. clear
. mkdir   폴더명 : Make Directory. -p
. rmdir  폴더명 : Remove Directory
. rm -rf 폴더명 : 강력하게 폴더 삭제 --> 주의!
. touch 파일명 : 빈 파일 생성
. cp 원본 타겟 : Copy
. mv 원본 타겟 : Move 이름변경 & 폴더 이동
. rm -f 파일명 : Remove.
. vi 파일명 --> 명령모드--> i --> 편집모드 --> (코딩작업)
  --> ESC --> 명령모드 --> :wq
. cat 파일명 : 내용 출력
